Theme Music loops for killer560's Mod (Menu Theme > Theme Extras > Theme Music)

theme_amber.ogg   Amber Loop     (Amber theme)
theme_dark.ogg    Dark Loop      (Dark theme)
theme_light.ogg   Light Loop     (Light theme)
theme_ocean.ogg   Ocean Loop     (Ocean theme)
theme_green.ogg   Viridian Loop  (Green / Viridian theme)

Original synthesized works by the mod's owner, killer560, who owns them and asked for them to ship with the mod.
Each track was written from scratch in a Python/numpy script from sine, triangle, band-limited sawtooth and filtered
noise sources, with envelopes, a lowpass and an echo. No samples, sample packs or downloaded audio, and no melody or
chord progression taken from an existing song. Each is a 64-second seamless loop, mono, 44.1 kHz Ogg Vorbis.

Licence: owned by killer560 and shipped with this mod at his request; any wider licence is his to grant. Music a player imports stays in their
own config folder and is never part of a release jar.

A sixth loop (edgerunners.ogg) exists for the planned Edgerunners theme. It is deliberately NOT in the mod: it ships
only when the owner says so (and the theme itself is not in the mod yet).
