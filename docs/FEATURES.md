# Killer560's Mod - Full Feature Descriptions

The detailed version of the feature list in the README. Keep this file up to date whenever a feature is added or changed - the public features Doc is generated from it.

> **Menu:** the mod menu (`/killer560`) has a header bar (the mod's version and build, a search box, and buttons for the Discord, the GitHub page and this document), a sidebar of categories - Home, Favourites, Dungeons, HUD, Chat, Items, Social, Cosmetics, Misc and Profiles - and a grid of feature cards. Every feature is its own card: its name, one line about it, and its on/off switch (a feature that is off has a dimmed card); only Secrets and Puzzle Solvers are grouped, as titled runs of cards inside Dungeons. Clicking a card opens that feature's settings in a drawer on the right, with its own switch, a star and a close button (the close button closes the drawer; Escape closes the menu, and the menu opens again on the same drawer, scrolled where you left it); every setting is a row with its label on the left and its switch, value or slider on the right, and Health and Mana Bars gets Basic and Advanced tabs for its Advanced section. The star on a card or in a drawer adds the feature to Favourites, which lists them as cards and, on Home, as a column of live switches; favourites are kept across restarts and in profiles. Ctrl F (or clicking the search box) searches every feature and setting, short names included ("etable" finds the Experimentation Table features): the arrow keys pick a result, Enter opens its drawer scrolled to the setting, and a feature result's switch turns it on or off in place. Home shows the version, the update channel and the last update check, buttons for Edit HUD, Edit Bars, Check Updates, Discord, GitHub and this document, the Menu Theme row, and cards for its own settings (Profiles is in the sidebar, and Favourites has its own page). Menu Theme (on Home as a row of buttons whose Customise... opens its settings, and as the round button at the right of the header: left click the next, right click the previous) picks the menu's colours: Amber (the orange look, the default), Dark (neutral greys), Light (light panels and dark text), Ocean (teal on navy) or Custom, where the accent, panel background, card background, text and on-switch colours are each set in the colour picker; changing a colour starts Custom from the preset you were on, and Reset puts that preset's colours back. Save as New Theme keeps the colours on screen as a saved theme (Custom 1, Custom 2...); each saved theme has Use, a name box to rename it and Delete (a second click confirms), and while one is in use, changing a colour changes that theme. Saved themes are kept across restarts and in profiles. Everything in the menu follows the theme - header, sidebar, cards, drawer, switches, value pills, sliders, the search and the tooltips - and it is kept across restarts and in profiles. The mod's own screens follow it too, with the same bevelled panels, wells and buttons: /profit and its trackers, Dungeon Profit (/croesus), Storage Search, the Run Log, the Inventory Sorter layouts, Custom Items, and the Bazaar and Auction House (their browsers and their reskins of Hypixel's menus). Each of those has a Theme setting in its feature's settings: Theme Default (follow the menu theme, the default) or Amber, Dark, Light, Ocean or Custom for that screen alone; the Bazaar and Auction House also offer Inventory Theme, the flat look they had before, which follows the Inventory Theme setting. In the cheat build every cheat-only feature sits in one red Cheat block at the bottom of its category, with cheat-only settings at the bottom of their drawer under a red header. The old New staging tab was removed on 2026-10-07. A setting that steps through several values (a mode, style, order, colour preset) shows its value between a ‹ and a › arrow: a click on the right half of the value goes forward, on the left half back, and a right click on it goes back, wrapping round at both ends; a click on the setting's name does nothing. Every colour setting opens the same colour picker (a saturation/brightness square, a hue bar and an alpha slider), which also has a hex box showing the colour that you can type into, Copy (puts the colour on the clipboard as #RRGGBB, or #AARRGGBB when it is see-through, and says "Copied"), Paste (takes #RRGGBB, RRGGBB, #RGB, 0xRRGGBB or #AARRGGBB from the clipboard, spaces ignored; anything else gets a red "not a colour" line and changes nothing; a colour without alpha keeps the setting's own see-through amount), Ctrl+C and Ctrl+V for the same while the hex box is not being typed in, and a Recent row of the last eight colours picked, copied or pasted in any picker, newest first: click one to use it, so a colour moves from one menu to another without the clipboard. Recent is kept across restarts and in profiles. The DVD text colour uses this picker too.

**Chat**
- Translate — auto-translates your chat messages into another language before sending
- Auto Correct — fixes common typos before you send
- Command Auto Correct — optional: fixes typos in command names you type ("/wardorbe" → "/wardrobe") against the server's real command list, never touching arguments
- Chat Emotes — shortcuts that turn into fun chat emotes
- Click Translate — click a chat message to see it translated
- Copy Chat — with chat open, hold Shift or Ctrl and Left-Click a message to copy the whole message (every wrapped line of it), or Right-Click to copy only the line you clicked. Text is copied without colour codes, a message stacked by Chat Hider is copied without its (xN), and a chat line confirms the copy. A plain click does exactly what it does without the mod
- Peek Chat — a key (or mouse button) that opens the chat history read-only: no text box, nothing you press types. Scroll it with the mouse wheel, Up/Down or Page Up/Page Down (Home goes back to the newest line); hover text and clickable links work as in normal chat. Escape or the Peek Chat key again closes it (a press, not a hold). Only opens with no menu open, and never touches a message you had half typed in the real chat. Off and unbound until you set it in Chat > Peek Chat
- Chat Hider — one switch over every chat tidier and hider (it replaced Hide Chat Messages and Chat Tidy on 2026-10-08; settings carry over). **Stack Duplicate Messages**: when a line arrives that repeats one of the last 50 messages in chat from the last 60 seconds (same text, same colours and formatting, same click action), the earlier copy is removed and one line ending in a grey (x2), then (x3) and so on, is added at the bottom, keeping the first copy's click and hover. Other messages in between do not stop it; the window keeps an old line from being pulled down from far up the chat. Blank lines and separator lines (----- or ▬▬▬) never stack, so back-to-back message boxes keep their spacing; signed player chat is left alone. **Hide Damage Messages**: hides Hypixel's combat spam, both families with one switch: "Your <ability> hit N enemy/enemies for N damage." (Implosion, Guided Sheep, Spirit Sceptre, Witherborn, Explosive Shot, Spirit Pet, Thunderstorm, Molten Wave and any other ability with that shape), and the hits you take: "A Crypt Wither Skull / Spirit Sheep / Chicken Mine exploded, hitting you for N damage.", "<boss, trap or mob> hit you for N (true) damage" (Maxor's Frenzy, Storm's Giga Lightning, The Arrow Trap, Wither TNT, Bonzo's Balloon...), "... struck you for N damage" (Stormy mobs, Spirit Chicken lightning), "The Lost/Frozen Adventurer used <ability> on you!" and "Your bone plating reduced the damage you took by N!". Only whole server lines are hidden: the same words typed by a player in any chat, or with anything else on the line, always show. Hiding is display-only: every other feature still reads the line, and the game log still records it. Heal lines (Wish, tether, fairy) are not touched. **Hide Useless Messages** ("There are blocks in the way!", "Profile ID: ..."), **Hide Discord Warnings**, **Hide Microsoft Warnings**, **Hide Empty Chat Messages**, **Hide Actionbar** and **Hide Non-Rank Invites** (party invites from players without a rank)
- Auto Meow — replies with a random cat noise ("purr~", "*slow blink*", ...) when another player says meow, purr, nya or mew, and replies in the same chat the message came from: party chat with /pc, guild with /gc, officer with /oc, co-op with /cc, a private message with /msg back to that player, all chat with /ac, and Mod Chat in Mod Chat (never through Hypixel). The channel is read from the whole chat line, so someone typing "Party > ..." in all chat is answered in all chat. Your own messages never trigger it, and it waits 3 seconds after each reply. Optionally plays a cat sound with its own volume
- Cringe — random one-liner messages for fun; `/cringe <chat>` picks the chat (pc, gc, oc, cc, ac, r, or kc for Mod Chat). Its first switch turns the whole feature on or off (on by default; it is also the switch on its menu card): off, `/cringe` and Leap Message's cringe line send nothing
- Spotify Mod — posts the lyrics of whatever you're playing on Spotify into chat, synced to the song. **No setup and nothing to configure**: open the Spotify desktop app and play something. It reads the app on your own PC directly — no account, no API key, no website, no login, and no source to pick. Only the artist and title ever leave the machine, to lrclib.net for the lyrics. There is no timing offset either: the app reports a track change instantly and the lyric clock stops while you are paused. Skipping forward inside a track is the one thing it cannot follow, because the app does not report your position. While an ad plays it says you are listening to an ad rather than leaving the previous song's last line up. Pick the chat it posts to (party, all, guild, plain, or Mod Chat), full lyrics or just the song title, and a profanity filter. Windows only
- Mod Chat — a genuinely private chat channel between mod users. Messages travel over the mod's own relay server rather than Hypixel's party or guild chat, so players who don't run the mod never see them. `/kc <message>` sends one line (like `/pc`, and Translate, Auto Correct and Chat Emotes apply to it the same way), and `/chat k` switches your typed chat into Mod Chat (like `/chat p`) until you pick another channel with `/chat a`, `/chat p`, `/chat g` and so on, which still go to Hypixel unchanged; leaving the server switches it back too. Received messages show in your chat by default (Log To Chat). The tab shows who else from your party or lobby is connected. Falls back to nothing if the relay is unreachable — it will never quietly post your message in public chat
- Voice To Text — speak and the transcription is sent to chat, by Push To Talk (hold a key, release to send) or Open Mic (always listening; what you said is sent once you stop talking for the Silence Before Send time, 1.0 s by default, 0.3 to 3.0 s). Open Mic tells speech from room noise by how far it rises over the quietest moment of the last few seconds, so a fan or a hissing headset does not hold it open; a blip shorter than about a third of a second, an empty result, or one that is only "uh"/"um"/"the" is not sent, and it keeps listening while the last sentence is transcribed. Fully offline (Vosk); on first use it downloads the Vosk engine (~26MB, checksum-verified) and a small speech model (~40MB) into the config folder, so neither is in the mod jar. Pick which microphone it records from, and which chat it goes to: party, all chat, guild, plain, or Mod Chat. **Untested with a real microphone**

- Auto Inventory Sorter — save the exact slot each item should live in as a named layout, then put your inventory back into it with a key or `/invsort apply <name>`. `/invsort` (or Open Layouts in the tab) opens the layouts menu: it shows a copy of your inventory, you move items around in it (click to pick up and click to drop, or drag), type a name and save. The same menu lists your saved layouts to load, apply, rename, delete or bind to a key (a keyboard key or mouse button). Applying opens your inventory and moves each item with real clicks: an item going to a hotbar slot moves with one hotbar-number swap, anything else is picked up and put down. Ticks Between Moves sets the clicks' pace and Random Extra Ticks adds up to that many more at random. It stops on its own if your inventory changes under it, if the inventory closes, or if another menu is open, and it leaves items Item Protect has Locked In Place where they are. Layouts are one file each so you can hand one to a friend. Items are matched by their Skyblock item id rather than material. Your movement keys are held off while it's sorting. `/invsort list` and `/invsort stop` are there too. **Cheat build only**
- Item Value Tooltip — adds an item's coin value to its tooltip anywhere in the game, from the same Bazaar-first/lowest-BIN price data the Croesus tools already use. Items with no known price simply get no line rather than a guess

**Cosmetics**

- Player Cosmetics (Cosmetics category) — one tab for how players look on your screen: Supporter Names and Supporter Sizes switches for other supporters' shared looks (each on its own; both off hides everything), Share if Supporter (one toggle that shares your display name, with its fade or letter colours exactly as you see it, and your own size once your account is linked as a supporter; players on an older version of the mod see the name in its first colour), and three dropdowns. Custom Names is the in-game name changer: your display name with a colour, a smooth per-letter fade between two colours, or a colour of its own for each letter, Name Animation for a faded or letter-coloured name (Off by default; Wave flows the colours along the name to the right in a smooth loop, Pulse dims and brightens the whole name; both are left click forward, right click back, with an Animation Speed from 0.25x to 3x - shared with the name, so other players on this version of the mod see it animate on your nametag, in chat and in the tab list, and older versions show it still), a live preview of the name as it will be painted (animated too), a reset back to your real name, and renames for other players; My Name in F5 (off by default) shows your own nametag above you in both third-person views, never in first person. Supporters' shared names show on nametags, in chat and in the tab list, Skyblock's text rows included, and every player's nametag follows their size so it stays just above the head from 0.05x to 2x. Player Size has My Size and Others' Size sliders from 0.05x to 2x, each with its own reset, plus your model's width/height/thickness. Held Item is the held-item transform. The name changer never recolours or renames anything inside this mod's own menus. Everything here is local rendering only — it never touches your hitbox, collision or reach, and anything *sent* to Hypixel (party invites, friend adds) always uses your real IGN, so renaming yourself can't break being partied or friended. If a nickname collides with a real account's name, chat asks which one you meant instead of guessing. There's a reset at the bottom
- Custom Items (Cosmetics category; was Armor Recolour) — client-side only: open the menu with Open Custom Items or `/customitems`, click any item in your inventory, armour or hotbar and change how it looks: a dye colour (dyeable items, which is most Skyblock armour), an armor skin and trim (armour), or a Look - any item model by id, or Copy Look and click another item (a player head's texture comes with it). Applies To picks this exact item (by its UUID) or every copy of it (by its Skyblock id). Saved looks are listed in the menu to pick or Remove; the tab has the switch and Reset All. Nothing is sent to the server and the real item never changes.
- Held Item Outline (Cosmetics category, off by default) — an outline, a fill, or a filled outline around the item you are holding, drawn on the first-person item model itself: not on the hotbar or the HUD (they draw on top of it), and nothing in third person, with F1, or with an empty hand. Style picks Outline, Fill or Filled Outline; Outline Color and Fill Color each have their own colour and alpha; Outline Side picks which face of the item the outline follows: Near (the default) hugs the face nearest you, Far hugs the whole shape including the item's thin sides (the original look), and Both draws around the near and the far face with a line joining them at every corner. A flat item (sword, bow, most items) and a block get all three; a model with no flat front and back (a shield) always uses Far. Outline Width is 1 to 10 screen pixels in half-pixel steps; Main Hand (on) and Off Hand (off) pick which hands get it. It shows whenever it is on, on any server: Skyblock Only does not hide it. It follows the item exactly through swings, eating and the held-item transform, since it is the item drawn a second time into its own mask
- Trail — a square dropped behind you each tick, green on the ground and blue in the air, with adjustable length, size, opacity and fade
- Name Changer — client-side only: change how your own name shows (one colour, a fade, or a colour per letter, which can Wave or Pulse) and rename specific players (chat, nametags, tab list, GUIs), each with its own colour picker. Bold Name draws your own display name in bold, and with Share if Supporter other mod users see it bold too (shared as an &l, which the relay already accepts). Lives in Player Cosmetics under Custom Names
- Trail — two styles. Squares: a square dropped behind you each tick, green on the ground and blue in the air, with adjustable length, size, opacity and fade. Ribbon: one smooth, continuous band streaming behind you from waist height, coloured from the head (at you) to the tail and fading out at the end, like a Roblox trail; set its width, how long it lasts, and its colours (two or three of your own, your Name Changer fade colours, or a flowing chroma). It shrinks back into you when you stand still. Either style can be hidden in first person. Only you see your trail; it is not shared
- Name Changer — client-side only: change how your own name shows (one colour, a fade, or a colour per letter, which can Wave or Pulse) and rename specific players (chat, nametags, tab list, GUIs), each with its own colour picker. Lives in Player Cosmetics under Custom Names
- Nickhider — its own tab in the Cosmetics category: Randomize Others gives every other player a stable fake name for the session. It works on its own, without the Name Changer toggle. Randomized Name (shown while Randomize Others is on) shows everyone as the base name you type plus a number instead - no two players share a number, each keeps theirs for the session, and changing the base name keeps the numbers; an empty base name falls back to made-up names

**Hud Elements**
- GIF Player — plays a GIF (with optional audio) as a HUD overlay. Ships with a built-in dancing cat girl GIF in every install, off until you switch it on; it is listed as "Dancing Cat Girl" and toggled like any other GIF, and DVD can bounce it too; your own GIFs in the folder are untouched and still show by default. GIFs are hidden while an inventory, chest, storage or any other menu is open
- DVD — the classic bouncing DVD logo screensaver on your screen; hidden while an inventory, chest, storage or any other menu is open. Its first switch turns the whole feature on or off (on by default; it is also the switch on its menu card): off, no box is drawn whatever each box's own switch says, and your boxes are kept
- Video Browser — watch YouTube Shorts in a small 9:16 window pinned over Minecraft (Windows only; uses your installed Edge or Chrome in its own profile, log into YouTube once). Keybinds for show/hide, next, previous, play/pause and mute work without leaving the game. Dark / Light / System / Amber theme option. Also plays normal YouTube, TikTok, Instagram Reels, Twitch or any URL; an edit mode to drag-move and resize the window; a zoom setting; a DVD-style bouncing placement; and a YouTube comments guard so next/previous does not fire while comments are open. **Untested**
- Health and Mana Bars — reads Hypixel's action bar (health, mana, defence, overflow mana, vitality, and any other current/max stat it shows with its own icon) plus the game's own experience bar, and draws your own bars and text from them. Turn on Stat Bars and choose a **Layout**: Predefined (the default for a new setup) puts the bars and texts in areas round the hotbar, the way Skyblocker's fancy bars work - two rows above the hotbar where every readout in a row gets an equal share of the hotbar's width, a column left of the hotbar and one right of it, and Hidden - stacked clear of whichever vanilla hearts, hunger, armour, air and XP rows are still showing, and following the window, GUI scale and HUD scale; in Edit Bars you drag a readout onto another area (the target lights up and the others make room) or onto the Hidden tray. Custom puts each one exactly where you drag it in Edit Bars. Both arrangements are kept, so switching back finds everything where it was; a setup from before the setting that already shows a readout stays Custom. The page itself is short (simplified 2026-10-12): Stat Bars, Edit Bars, an on/off for each bar, Style and Text Size. Everything else is under **Advanced**, closed until you open it and left as you leave it (the menu search still finds the settings inside): the layout, the bars' look, every colour in one grid, the text readouts and the vanilla hides. The bars: Health (absorption - health past max on the action bar, or the game's own absorption - is its own segment in the Absorption Colour straight after your health, like golden hearts, and the health fill stays your health out of max), Mana, Defence (shown as damage reduction, defence / (defence + 100)), Vitality (the resource healing abilities, Wither Shield and Creeper Veil spend; Hypixel shows it on the action bar only while it is in use), Other Resource (anything else current/max with its own icon) and XP (the level and progress the game has - on Hypixel that bar is sometimes a countdown instead, and then that is what it shows). Advanced holds the shared bar length and thickness, the on/off number on the bar, and the colours: each bar that is on, Absorption, Overflow Mana and the background, in one grid. **Bar Style** sets their look: Bold (the default) has a black and orange double rim, a glossy two-band fill and notches at every quarter; Sleek has a thin dark frame, a sunken track with a soft inner shadow and a gradient fill with a light top edge. Both draw the stat's own item as an icon at the bar's left (a golden apple for health, an enchanted book for mana, an iron chestplate for defence, Hypixel's ♨ Vitality symbol, outlined in the Vitality Bar's colour, for vitality, a bottle o' enchanting for XP, a clock for the other resource). You also choose Rounded (a two-step curve) or Square corners, Icons on or off, whether the number sits Inside the bar or Beside it (after its end, in the bar's colour, the bar shortened to fit in the same box; bars stacked in one column keep room for the widest number among them, so they end at the same length), Text Size (Small, the default, or Normal, both with a dark outline all round the digits), Smooth Fill (the bar slides to a new value instead of jumping) and Damage Ghost (after a drop a pale strip shows where the bar was, holds for a moment and drains down). Health's absorption and the mana bar's overflow mana show as their own layer in their own colour (Absorption Colour, Overflow Mana Colour, a deep blue by default) after the value, ending at the bar's end at most. The icon and a Beside number take their room inside the bar's own box, so placing and resizing in Edit Bars works the same in every style. A bar showing its number is always at least the number's height plus one unit above and below it (12 units, a little thinner than the 14 it was before 2026-10-13; a Bar Height above that is drawn as set), and the number keeps four units clear of each end - when the full "current/max" does not fit, only the current value shows, and on a very short bar none. In the Predefined layout every bar and text shares one size (scrolling any of them in Edit Bars resizes them all together; it is saved like any setting) and every bar is the Bar Height thick, so a row never mixes sizes; Custom keeps each one's own scale and size. The bars and texts stay drawn while an inventory, chest or any other screen is open, behind it the way vanilla's hearts and hotbar are **Text readouts** (in Advanced): the same stats as text in the same places, plus Overflow Mana, Intelligence (worked out from max mana, which is 100 + Intelligence) and Effective Health (health x (1 + defence / 100)), and a text shadow. **Hide** (in Advanced): the hearts/hunger/armour/air set that only acts while Stat Bars is on (with Unhide Hearts In Rift), and the always-on hides for the vanilla health, absorption, mount health, regeneration bounce, armour and hunger bars, the XP bar with its level, and Hypixel's own stat text on the action bar (only the stat numbers go - "5/7 Secrets" or an ability name on the same line stays). Held Item Name sets vanilla's item name that pops up over the hotbar when you switch slot: Hidden Over Bars (the default) hides it only where it would land on one of these bars or texts, Hidden always hides it, Shown never does. The number on a bar is centred on it, to the pixel, in both layouts. Every bar and text is its own HUD element, moved and scaled in Edit Bars, where in Custom a bar's edges also drag its length and thickness on their own (the Bar Width / Bar Height sliders set every bar at once). True Defence is not offered: Hypixel never puts it on the action bar, only in the /stats menu. The old one-line Classic Display is gone; a saved setup that used it and no other readout comes back as the matching Health/Mana bars and Health/Mana/Defence texts where it was

**Helpers**
- Performance HUD — your real ping to the server (a measured round trip, once a second, the way Odin and Skyblocker do it; Hypixel's tab list always says 1 ms) and the server's TPS. Previously called Lag Display; the "server lag" readout was replaced with a real TPS figure and the text bar at the bottom removed
- Quiver Display — shows the real "Arrows Remaining" count from any real arrow/quiver item anywhere in your inventory or off hand, in a text colour you pick, with an optional Low Arrow Alert (an on-screen title and a sound, text editable with & codes and {count}) when you drop below a threshold of 20 to 200 arrows
- Experimentation Table Solver — solves Chronomatron, Ultrasequencer, and Superpairs by highlighting the answer: you click, it just shows you where. It is its own setting rather than a mode, so you can run it on its own. The **cheat** build adds a separate Auto E-Table section that clicks for you, independent of the solver - either, both or neither can be on; its auto-swap to your best Guardian pet before a run is on by default. In Superpairs it plays in turns, counts what is left on the board to deduce hidden tiles, and takes money before XP; Skip Grand XP Bottles and Skip Guardian Pets (two switches) leave those for the very end, only if clicks remain; powerups work as on Hypixel (a powerup never takes a turn's click, +Clicks is a free space, Instant Finds stack); when the board's clicks run out it presses Escape once, which takes you to the rewards to claim. Any key, mouse click or scroll of yours stops a run (moving the mouse does not), as does opening another screen such as chat; the click on Start ETable that began it does not count, and chat says what stopped it - see [Which jar do I download?](#installing) below.

The same run on the shipped defaults at the same speed collided on 17 of 219, and the anticheat reported 17 movement violations: the same 17. So the flags were the collisions. That is worth stating plainly in both directions - the slow setting is what desyncs you at speed, because you walk into blocks being removed on that same tick; and ten interaction packets in one tick is not a rate a hand can produce and is visible as exactly that. - Auto Anvil — in Hypixel's Anvil, puts two identical enchanted books in and combines them into the next level, one click at a time, waiting for the server to show each step before the next. Books with more than one enchantment, recombobulated books, stacks and protected items (Item Protect) are left alone. It only combines where the anvil can make the next level for that enchantment (two Sharpness IV make V, two Sharpness V make nothing, Looting stops at III, Infinite Quiver goes to X), and an enchantment it has no rule for is never combined. - Bazaar Flipper — buys an item out of the Bazaar at instant-buy price and sells it to the `/trades` NPC, picking whatever product currently has the best return. **Cheat build only**, off by default and unbound by default. Your keybind starts it and **any key stops it** (the stop message names the key); it also stops on a target purse, on nothing clearing your profit floor, on not having the coins, and on any menu it did not expect.
  - *How it prices a flip.* Two different Hypixel endpoints: the Bazaar order books, and `npc_sell_price` from the item resources list. For each candidate it walks the real instant-buy order book cheapest level first, so the rising price as a purchase eats through the book is paid for rather than ignored, and stops at the first of three limits — a level priced at or above the NPC price, a full inventory (36 slots at the item's real stack size), or your purse running out. `quick_status.buyPrice` is deliberately not used: it is a weighted average and matched the exact top of the book on only 628 of 1833 products when this was measured, so it overstates what a purchase realises.
  - *Ranking.* Either **Percentage Margin** or **Total Profit Per Run**. A third option, profit per coin invested, was dropped because it orders identically to percentage margin.
  - *Minimum Profit Per Run* applies in both modes, and percentage ranking is close to useless without it: the top of the percentage list is things like Netherrack at 900% (buy 0.1, NPC 1), which nets under two thousand coins for a whole inventory cycle. Default 250,000.
  - *Target Purse* stops it once your purse reaches that number; 0 means no target.
  - *Failsafe for not having the money.* Your purse is passed into the sizing, so an item you cannot fully afford is simply costed at what you can afford, and if that no longer clears the profit floor the next best item wins on its own merits. If nothing clears the floor it refuses to start and says how many products are profitable at all.
  - *Scanning.* Once on start, then once a minute **while running only**. Nothing scans in the background while it is idle. `/bazaarflip scan [n]` prices the market once and prints the ranking without touching a menu.
  - *Speed* slider (1-10) sets the gap between two consecutive automated actions — 700-1300 ms at 1, down to 160-310 ms at 10, drawn randomly inside that band each time. It does not change how much is bought and does not shorten any safety timeout.
  - *The cycle.* `/bz <item>`, the item in Hypixel's search results, **Buy Instantly**, then on the Instant Buy page the largest of **Fill my inventory!**, **Buy a stack!** or **Buy only one!** that stays within what the scan found profitable, your free space, your purse and (when the button shows a price) below the NPC price. Then it closes the Bazaar, opens `/trades` and shift-clicks every unit to the NPC, waiting for each stack to go, and scans again. Every page is recognised by name, never by slot number, and anything unexpected stops it with the menu's contents in chat. The Bazaar reskin keeps drawing while it runs, showing each page it reaches with "Bazaar Flipper running - any key stops it" in the bottom bar; the flipper reads and clicks Hypixel's real menu underneath, and a key or click on the reskin stops it. It needs an active **Booster Cookie** (remote `/bz` and selling from `/trades` both require one) and refuses to start without.
- Auto Kick — Party Finder only: while you queue, each player who joins your group through Party Finder has their time on the floor you are queuing looked up, and a slower one - or none at all - is warned about in chat or kicked. **Warn Only by default**, and off by default; Kick is opt-in. **AP3 - automated F7/M7 Phase 3 (cheat build only)**

AP3 walks, aligns, leaps, uses items and times you through the F7/M7 Goldor phase (P3, sections S1-S4) along a route of *nodes* you place yourself. It only ever presses real keys - W/A/S/D, sneak, sprint, jump - and turns your real view, exactly like a player would; it never writes your position or velocity. When the server corrects your position it posts a chat line and plays the Correction Alarm, and AP3 carries on from where the server put you (since 2026-10-06; the old Stop On Server Corrections switch and the two-in-ten-seconds auto-disable are gone). Use it on your own risk - it is automation and against Hypixel's rules.

*How it runs*
- Every node has a small trigger box (0.5 or 1 block by default, or any size with w<n> l<n>). Walking INTO a box fires that node; the ones you are already standing in do not fire again until you leave and come back.
- Nodes fire one per tick in a fixed priority: Stopwatch, Stop, Align/Axis Align/Fast Align, Look, Terminal, Leap Counter, Walk/Run, Jump/Edge/Block, Boom, Leap. A queued node waits for the one before it. Look, Stopwatch and Use never wait: they go off on the tick you enter their box, whatever else is running (a Use waits only while something else is aiming you - an align, a Block, a Boom, a Path, a Leap or a Terminal). Walk/Run, Jump and Edge do the same unless a Stop, an align, a Leap or a Path is running or queued ahead of them.
- AP3 knows which section you're in and only arms that section's nodes. Force Dungeon (in the tab) lets you place and test nodes anywhere, and Test Mode runs nodes without waiting for terminals or teammates.
- Freeze View (Freecam): while AP3 turns your real yaw for an align or a walk, your screen keeps the view you had and your mouse moves only the view. Your model in F5 and the server see the real angle.
- Moving yourself (WASD/space) stops AP3 at once - except inside an Align, which takes your keys over until it has landed.

*Placing nodes* - `/ap3 add <type> [modifiers]`, or a keybind for each type
- Nodes snap to the nearest half block (a block centre, or the line between two or four blocks) unless you add `precise`; the height is your exact feet height, so nodes on carpet or slabs sit on top.
- The angle recorded is where you are looking (or where your free camera looks while Freeze State is on). Only the nodes that use an angle keep it: Walk and Run keep the yaw, Look, Boom, Block and Use keep yaw and pitch, and every other node is saved without one.
- `/ap3 edit <n>` opens the node editor: position, box, wait, jump/edge and the fields that node's type actually uses. The type is a dropdown; picking another type adds or removes rows on the spot (switching an Align to a Look adds Yaw and Pitch, starting at your current view). A Use node's item is a dropdown of your hotbar - click the item to use, or "Held item / none"; an item saved earlier that is no longer on the bar still shows. Nothing is applied until Save.
- `/ap3 list`, `/ap3 undo`, `/ap3 redo`, `/ap3 delete [n]`, `/ap3 replace <n>`, `/ap3 clear`, `/ap3 reload`, `/ap3 stop`, `/ap3 testmode`. Routes are saved per config file in the killer560smod-ap3 folder; Choose AP3 Config switches between them. `/ap3 undo` now takes back the last add, delete, move, re-place, editor change or clear, whatever area it was in and as many steps back as you like (until the game closes or `/ap3 reload`) - it used to remember only the last added node; with nothing left it still deletes the last node of the chain you stand in. `/ap3 redo` (and its keybind) re-applies what undo took back; any new change clears the redo history. Sliders in the AP3 tab are not undo steps.

*Node types*
- **Align** - lands you on the node's point to within 0.001 of a block, typically in 6-9 ticks from entering at speed. It plans the fastest landing each tick, mixing turning your real yaw, every key combination and sneak taps, and only counts as done once you have actually stopped.
- **Axis Align** - for a node placed against a wall: walks you into the wall (which pins that coordinate exactly), then holds one key into the wall at a small angle that steers you along it until you stop exactly on the point, without ever pulling off the wall.
- **Fast Align** (`/ap3 add fastalign`) - an align built only for speed: each tick it plans the fewest ticks until you are standing still on the point (within 0.001), combining a camera turn to any angle with any key combo and sneak, so it brakes with a sneaking tap against your momentum instead of coasting to a stop. In testing it finishes in 3 ticks about 83% of the time and never takes more than 4, where the regular Align takes 8-11 (up to 16).
- **Path** (`/ap3 add path [start|end] [<step>]`) - the route optimiser. Each Path node is a numbered step: `/ap3 add path 2` or `/ap3 add path two`, and with no number it takes the lowest one still free (place 1 and 3, the next one becomes 2). Nodes that SHARE a number are one step to be done in any order - put both levers on step 2 and it works out whether to take them one after the other or, if their boxes overlap, run between them and take both on the same tick. Place Path nodes in order and it works out the fastest way to hit every one of them, from the first to the last, without skipping any: it searches the real movement model a tick at a time (key combination, yaw and jump) and plays the answer back through the same key-writing every other node uses. Modifiers: `exact` (keep the block relationship you placed it with - the hitbox covers the same blocks, on or off an edge - rather than a meaningless decimal match), `speed:<min>-<max>` (the speed window it must cross at, blocks per tick; `speed:0.4-` at least, `speed:-0.3` at most), `dir:<deg>` with `dirtol:<deg>` (the heading it must be travelling at), and `term` (stop here, wait for a terminal to be closed, and plan the next leg from rest - a term costs you all your speed, so there is no point arriving fast). A Block node's block is understood too: the spot it will place is treated as floor for two ticks of running (a bottom slab at most), and the route never places it itself. Whether it jumps is worked out, not assumed: the air only accelerates you at a flat 0.026 no matter your speed stat, so bunny-hopping wins at vanilla speed and loses badly at 550. The world is read into a snapshot of its real collision boxes each time it plans, and every tick of the search sweeps your 0.6x1.8 hitbox against them the way the game does - one axis at a time, with the same step-up search - so stairs, slabs and ledges are planned on what actually happens rather than on a height profile. That is what lets a route run up a staircase: it climbs half a block a tick and knows that each riser takes your speed with it, so it plans around the climb instead of expecting to keep sprinting through it. Blocks Breaker Aura is going to break count as air, lava is somewhere the route may not go, and the plan is drawn through the world at the heights it will really run at. Mark the two ends of a route with `start` and `end`: one section can then hold several separate routes and each knows where it stops, instead of running on into the next one. To extend a route, delete its `end` node and place a new one further along. A chain with no `end` marked anywhere behaves as it always did and runs to the last Path node in it. Each way of arriving at a route is searched ONCE. The first time you run it from a given spot the search is allowed to think hard - seconds, a wide beam, several differently-shaped searches, and a longer second attempt if the first ran out of clock - and the answer goes in the config folder; arrive that way again and it loads instantly and runs exactly the same, because a saved plan is never replaced once it exists. Arrive somewhere quite different and it searches once more and remembers that approach too. What it will not do is hand back a plan built somewhere else: a plan is a fixed schedule of key presses, and replayed from the wrong place it does not go to the node, it repeats the movements that went to the node from another one. `/ap3 regenerate` forgets the plans for the route you are standing in, so the next run searches again. When a route is too tangled to plan in one piece - a gap, then a ledge, then a climb - it is cut up and planned a piece at a time, landing on each cut point, because a route that pauses is worth more than a route that does not exist. A route that never leaves the ground always wins over one that jumps, however the tick counts compare, and running into the world costs the search real ticks so it will coast, walk or take off early to keep a clean line - though a collision that gains height is how you climb a step and is charged nothing.
- **No Go** (`/ap3 add nogo`) - a GHOST BLOCK: solid to the route planner, absent from the world. It never fires as a node and nothing is ever placed or sent; it simply tells the route there is a block here even though there is not, so the route can stand on it, step up it, be stopped by it and jump off it. Use it to build the geometry a movement needs when the room does not provide it. A full block on the node's own level, sized by the node's box.
- **Term Aura** (`/ap3 add termaura`) - steps on it and clicks a terminal in range once to open it, trying again two ticks later if nothing opened. A terminal your look misses gets your body - never your camera - turned to it first (Terminal Aura's Turn To Terminal setting), and the chain carries on under the terminal it opened, so a Terminal node after it takes over. It does not turn the Terminal Aura setting on or off - it is one pulse of it.
- **Walk / Run** - keeps you walking (or sprinting) in the direction the node was placed, until another Walk/Run (which takes over), a Stop or an align (which end it), a Leap (which drops all movement) or a Path (which takes the movement over). Every other node fires with the walk still going; while a screen a node opened is up (a terminal) the walk presses nothing and carries on when it closes. A Stop or align hit while another node is still busy ends the walk at once. Your real yaw snaps so W+A / W+D (45 Degree Strafe on, the faster diagonal) or W points exactly along the walk from the first tick. On the tick a jump goes in it faces straight ahead so the sprint-jump boost follows the walk, then strafes again in the air.
- **Jump** - jumps on the next tick after you enter it (waiting up to a second for the ground). Does not end a Walk/Run.
- **Edge Jump** (`edge`) - jumps as late as the game allows when you run off a block: on the one-tick "coyote" window just after your feet leave it. Does not end a Walk/Run.
- **Block** - places a block (the held block, else a slab, else any block in your hotbar) where you were looking when you placed the node, then swaps back to what you held. The block shows on your screen at once, so you can run across ghost slabs. Does not end a Walk/Run. Like Use, it places on the tick you enter its box: the swap and the place are the first things sent after the movement packet that put you there, and the swap back goes out once, the tick after.
- **Look** - turns your view to the node's angle on the tick you enter its box - the next frame already shows it - client-side only (no rotation is sent). During a walk only the view turns (the walk keeps its own heading underneath, as with Freeze View); when the walk ends your real rotation glides onto the look.
- **Use** - right-clicks along the node's angle on the tick you enter its box: the click is the first thing sent after the movement packet that put you in the box, swapping first to the item you held when you placed it if it is elsewhere in your hotbar (slot change and click in the same tick, like a hotbar key and a right click). The click carries the node's angle and the next movement packet reports the same angle, as a real client's does. A block in reach is clicked (a lever, a chest), otherwise the item is used into the air. Does not end a Walk/Run.
- **Boom** - uses a Superboom on the block along the node's angle, on the tick you enter its box (swap and tap sent first thing after the movement packet that put you there). Does not end a Walk/Run.
- **Leap** - opens Spirit Leap and leaps to a class, a player, or your Fast Leap target. **Leap Counter** waits until that many teammates have leapt to you.
- **Terminal** - waits for the terminal you're at to be done (a Walk/Run carries on - put a Stop before it to stand at the terminal; nothing moves while the terminal is open). **Stop** - lets go of every key and waits until you've stopped.
- **Stopwatch** - the first one starts a timer, the next one stops it and prints the time. Name the starting one (`/ap3 add stopwatch s3`) and, with Send Stopwatch to Party on, the time goes to party chat as "s3 took 12.345s". The Stopwatch HUD shows the time while it runs and for 10 seconds after it stops, then hides until the next start (the HUD editor always previews it).

*Modifiers* (any node, after the type)
- `w<n> l<n>` (also `w.5`, `.5x.5`) - the trigger box size. `precise` - no snapping. `wait:<ms>` - hold the next node that long after this one. (The old `close` modifier is gone; chains saved with it still load and the node simply fires when you walk into it.)
- `jump` / `edge` - after the node has done its part, jump (or edge-jump). `/ap3 add run edge` runs at the node's angle and jumps at the edge.

*Display*
- Node boxes with arrows (walk direction), wall markers (axis align) and look rays; labels with number, type and details; a colour per node type (or one colour for all); Show Nodes and Show Node Lines to hide them; Node Messages (None / Simple "Added #3 Walk" / Detailed, which also shows the queue).

*Freeze State* (its own red tab; never use it on Hypixel)

- Rewind 1 Tick / Forward 1 Tick keys: rewind puts you exactly where you were one tick before your current position (Rewind Memory sets how many ticks are kept); forward predicts - the game runs exactly one real tick from where you are.
- AP3 keeps running while frozen: each forward step runs one AP3 tick, and your own keys and mouse never move the character - only the nodes do.

A profile carries everything you set up, not only the settings: your GIFs, crosshair presets, the scoreboard background image, AP3 routes, Breaker Aura configs, inventory layouts, the cringe lines and the sim's speed and keys all travel with it, and loading a profile replaces them as a set (a GIF the profile does not have goes away; a GIF on the HUD switches straight away). A blank profile starts with none of them except your AP3 routes and Breaker Aura configs. Left out on purpose: credentials and keys (session login token, per-account proxies, the proxy password, the Last.fm login, the Profile Viewer API key - your own stays when you load a profile), downloads and caches (the room database and room library, island graphs, the speech model, Auction House and item caches, the video browser's browser profile, Auto Update downloads), logs and bug reports, and history (run history, Croesus and Experimentation logs, tracked players, Fairy Souls found). Profiles move between versions: a profile made on 26.1.2 or 26.2, on the cheat, legit or testing build, or on an older version of the mod, imports and loads on any other - settings a build does not use (cheat settings on the legit build) are kept and come back when it returns to a build that uses them, settings it does not know take their defaults, and a damaged or newer-version file is reported instead of breaking the import. A profile from before profiles carried files only changes settings when loaded. While a profile is loaded, every setting and file you change is saved into that profile too, so switching away and back keeps your changes

- Minecraft `26.1.2`
- [Fabric Loader](https://fabricmc.net/use/) `>=0.19.3`
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java `25`+
