# Thresholds for tools/bench/regress.sh (FloorBench -Dcheck=this file). Set 2026-10-04 from the run that introduced
# WarpGraph. The warp counts and found rates are seeded and do not move unless the code does, so their limits are
# tight; the times depend on the machine and only catch a gross slowdown. Any invalid hop, any click the old
# planner finds and the new one does not, and any click where the exact heuristics change the warp count also fail.
#
# Whole floors (3 x 150 clicks). Re-measured 2026-10-04 (fix-bench) after the bench was made to build the game's
# floors: the room database's types and shapes loaded (puzzles and traps placed, no L rooms) and only the
# SimFloorLayout.doorLinks tree carved, every other doorway sealed. The 2026-10-04 WarpGraph numbers (100%, 7.53
# warps, old 13.50) were taken on floors the game never builds - 3 to 8 extra loop doors each, L rooms with a void
# quarter, no puzzles - so the mean is not comparable. Measured now: found 100%, mean 8.26 warps (old planner 15.84,
# 92.4% found), warm median 0.84 ms, p99 4.3 ms. On the same floors the every-landing full-aim reference needs 7.81
# warps against the graph's 8.19 (180 clicks), so 7.55 was not reachable by any planner here.
full.minFoundPercent=100
full.maxMeanWarps=8.28
full.maxMeanWarpsOverOld=0.60
full.maxWarmMedianMs=2.0
full.maxWarmP99Ms=12

# game's floors (2026-10-04, fix-bench): found 100%, mean 3.43 against 3.29 (x1.043), 51 of 400 one worse, 3 two.
small.minFoundPercent=100
